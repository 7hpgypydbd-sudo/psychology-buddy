# Psychology Buddy

A calm companion for fortnightly psychology sessions, made for iPhone and played as a web page (open in Safari, Share, Add to Home Screen).

- Paste a session summary: it becomes to-dos, things to practise, insights and a short "backup coach" note.
- Log thoughts, feelings and moments with tags (mood, feelings, physical symptoms, sleep, triggers, people), all date-stamped.
- Before a session: themes from your notes and a "Give me something to talk about" button.
- After a session: mark what you talked about, jot the outcome, set the next date.
- Calm (light) and Night (dark) looks, reminders, a code / Face ID lock, password-locked backups.

**Privacy:** this repo holds only the app's code. Everything you write is saved on your phone only. Text goes to Claude only when you tap an AI button, using your own API key.

Files: `index.html` (layout and styles), `app.js` (everything else), `sw.js` (works offline), icons and `manifest.webmanifest`. Served by GitHub Pages from `main`.
